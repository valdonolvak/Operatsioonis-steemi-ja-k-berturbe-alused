Arvuti alglaadimine: toitenupust töölauani

Kaheksa sammu näitavad, millises järjekorras püsivara, alglaadur, tuum ja süsteemiprotsessid käivituvad ning milline fail igal sammul kettalt mällu laaditakse.

Sammud

Proovi ise

Ava PowerShell administraatorina ja uuri oma arvuti alglaadimist.

bcdedit /enum                       # Boot Manager ja OS-i laaduri kirjed BCD-s
Confirm-SecureBootUEFI              # kas Secure Boot on sees
Get-Tpm | Select-Object TpmPresent, TpmReady
mountvol S: /S ; dir S:\EFI\Microsoft\Boot ; mountvol S: /D   # ESP sisu
Get-WinEvent -LogName 'Microsoft-Windows-Diagnostics-Performance/Operational' -MaxEvents 5 |
  Where-Object Id -eq 100 | Select-Object TimeCreated, Message   # alglaadimise kestus
