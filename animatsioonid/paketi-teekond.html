Paketi teekond: mis juhtub, kui avad veebilehe

Animatsioon näitab, millised paketid liiguvad arvuti, kommutaatori, ruuteri ja serverite vahel ühe veebilehe avamisel ning mida samal ajal näeb Wireshark või pktmon.

Sammud

Proovi ise: vaata pakette oma arvutis

Windowsis (PowerShell administraatorina):

arp -a                                   # ARP-vahemälu: lüüsi MAC-aadress
Resolve-DnsName www.ria.ee               # DNS-päring
ipconfig /displaydns | more              # DNS-vahemälu
Test-NetConnection www.ria.ee -Port 443  # kas TCP-ühendus porti 443 õnnestub
tracert -d www.ria.ee                    # teekond hüpete kaupa
Get-NetTCPConnection -State Established | Select-Object RemoteAddress, RemotePort, OwningProcess

pktmon start --capture --pkt-size 0 -f $env:TEMP\v6rk.etl
# ava brauseris mõni leht
pktmon stop
pktmon etl2pcap $env:TEMP\v6rk.etl --out $env:TEMP\v6rk.pcapng   # ava Wiresharkis

WSL-is või Linuxis:

sudo tcpdump -i eth0 -n 'port 53 or port 443' -c 20
traceroute -n www.ria.ee     # või: mtr -n www.ria.ee
ip neigh                     # ARP-tabel

Kasulikud Wiresharki kuvafiltrid: arp, dns, tcp.flags.syn == 1, tls.handshake.type == 1, ip.addr == 203.0.113.10.
