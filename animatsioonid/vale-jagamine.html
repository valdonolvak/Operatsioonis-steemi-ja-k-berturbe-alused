Vale jagamine: kuidas üks vahemälurida kaks tuuma aeglaseks teeb

Animatsioon näitab MESI-protokolli abil, miks kaks lõime, mis ei jaga ühtegi muutujat, võivad üksteist siiski takistada, ja kuidas joondamine selle lahendab.

Sammud

Mõisted

MõisteSelgitus
Vahemälurida (cache line)Väikseim ühik, mida vahemälu liigutab. Tänapäeva x86- ja ARM-protsessorites tavaliselt 64 baiti.
Vahemälu koherentsusNõue, et kõik tuumad näeksid sama muutuja kohta sama väärtust, kuigi igal tuumal on oma vahemälu.
MESIRiistvaraprotokoll, mis peab iga vahemälurea kohta arvet nelja oleku abil.
M (Modified)Rida on muudetud ja ainult selle tuuma vahemälus. Põhimälus on vana väärtus.
E (Exclusive)Rida on ainult selle tuuma vahemälus ja muutmata. Kirjutada saab kohe.
S (Shared)Rida on mitme tuuma vahemälus. Lugeda võivad kõik, kirjutamiseks tuleb teised koopiad kehtetuks tunnistada.
I (Invalid)Koopia on aegunud. Enne kasutamist tuleb rida uuesti tuua.
Vale jagamine (false sharing)Eri lõimede eri muutujad asuvad samal vahemälureal ja rida liigub kirjutamisel pidevalt tuumade vahel.
Tõeline jagamineMitu lõime kirjutavad päriselt sama muutujat. See vajab lukku või aatomtehet (ptk 8).
Joondamine (alignment)Andmete paigutamine nii, et need algaksid vahemälurea piirilt ja täidaksid terve rea.
Spinlukk, järjekorraga spinlukkLukk, mida oodatakse tsüklis. Järjekorraga variandis ootab iga tuum oma muutujal, et luku rida ei põrkaks.

Proovi ise: mõõda vale jagamist

Kleebi PowerShelli. Programm käivitab kaks lõime, millest kumbki suurendab oma loendurit 200 miljonit korda. Esimesel korral on loendurid massiivis kõrvuti, teisel korral 128 baiti lahus.

Add-Type -TypeDefinition @'
using System; using System.Diagnostics; using System.Threading;
public static class ValeJagamine {
    static long[] a;
    static void Too(int i) { for (long n = 0; n < 200000000; n++) a[i]++; }
    public static long Moota(int vahe) {
        a = new long[64];
        var sw = Stopwatch.StartNew();
        var t1 = new Thread(() => Too(0));
        var t2 = new Thread(() => Too(vahe));
        t1.Start(); t2.Start(); t1.Join(); t2.Join();
        return sw.ElapsedMilliseconds;
    }
}
'@
"Samal real  (indeksid 0 ja 1):  $([ValeJagamine]::Moota(1)) ms"
"Eri ridadel (indeksid 0 ja 16): $([ValeJagamine]::Moota(16)) ms"
  • Add-Type -TypeDefinition @'…'@ kompileerib tekstina antud C#-koodi ja teeb klassi PowerShellis kasutatavaks.
  • static long[] a on loendurite massiiv. Iga long on 8 baiti, seega kaheksa kõrvuti elementi mahuvad ühele vahemälureale.
  • Too(int i) suurendab elementi a[i] 200 miljonit korda.
  • Moota(int vahe) käivitab kaks lõime: üks töötab elemendiga 0, teine elemendiga vahe. Stopwatch mõõdab aega, Join ootab, kuni lõim lõpetab.
  • Eelviimane rida: vahe = 1, loendurid on kõrvuti samal real.
  • Viimane rida: vahe = 16, loendurite vahel on 16 × 8 = 128 baiti ehk need on kindlasti eri ridadel.

Teine tulemus peaks olema mitu korda väiksem, kuigi mõlemal juhul tehakse täpselt sama palju tööd. Täpne vahe sõltub protsessorist. Kui esimesel käivitusel ilmub viga „type already exists“, ava uus PowerShelli aken.

Vahemälu suurused sinu protsessoris

Get-CimInstance Win32_CacheMemory |
  Select-Object Purpose, @{n='Suurus KB'; e={$_.MaxCacheSize}}, Associativity

Näitab L1-, L2- ja L3-vahemälu suurust. Rea pikkust see käsk ei näita; selle näitab Sysinternalsi tööriist Coreinfo (coreinfo -l).
